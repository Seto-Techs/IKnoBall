IKnoBall

The word IKNOBALL with a basketball in place of the O. All caps, 12° forward lean, flat sheared terminals, navy body, orange seams. Every asset below is real vector — scale it to any size.

Files

File Use it for
iknoball-primary.svg Default. Navy on light backgrounds.
iknoball-white.svg On navy, ink or photo backgrounds.
iknoball-cream.svg On navy when pure white is too cold.

iknoball-upright.svg Documents and print, where an italic mark is wrong.

How to use it — React

// Preferred in the app: inherits colour, no network request.
import { Logo, LogoMark } from '../components/brand/Logo';

// Nav / header — 28px, navy
<Logo className="h-7 w-auto text-brand-navy" />

// Landing nav and footer — white on navy
<Logo className="h-7 w-auto text-white" />

// Auth cards, and anything under 36px
<LogoMark className="h-12 w-12 text-brand-cream" />

// Optional props
<Logo mono />      // seams in currentColor instead of orange
<Logo upright />   // drop the 12° lean

currentColor paints the letters and the ball body, so any text utility recolours the whole mark. Keep build.mjs and Logo.tsx in sync — both are generated from the same glyph table.

How to use it — plain HTML

<!-- As an image: served at /brand/ from the frontend's public dir -->
<img src="/brand/iknoball-primary.svg" alt="IKnoBall" height="28" />

<!-- Inline: lets CSS recolour the whole mark via currentColor -->
<img src="/brand/iknoball-primary.svg" alt="IKnoBall"
     style="height: 28px" />

<!-- Favicon (already wired in apps/frontend/index.html) -->
<link rel="icon" type="image/svg+xml" href="/brand/iknoball-icon.svg" />
<link rel="apple-touch-icon" href="/brand/iknoball-app-icon.svg" />

Rules

  • Minimum clear space equals the ball radius on every side.
  • Navy on white, or white/cream on navy. Never cream on white — it is about 1.1:1.
  • Orange is for seams and the active nav underline only. It is not a text colour.
  • Do not rotate, re-colour the seams separately, add a shadow, or set the wordmark in a different typeface.
  • Do not stretch it. Scale from the height and let the width follow.
